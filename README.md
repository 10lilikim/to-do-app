# To Do List

순수 HTML/CSS/JavaScript로 만든 할 일 목록 앱입니다.

## 주요 기능

- 할 일 추가 (입력 후 Enter 또는 추가 버튼)
- 할 일 완료 체크
- 할 일 삭제
- 상태별 필터링 (전체 / 진행중 / 완료)
- 완료된 항목 일괄 삭제
- 중복 항목 등록 방지
- `localStorage`를 이용한 데이터 저장 (새로고침해도 목록 유지)

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

## 파일 구성

- `index.html` - 페이지 구조
- `style.css` - 스타일
- `main.js` - 할 일 목록 로직
