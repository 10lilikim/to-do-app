# 📝 Todo App (나의 할 일 목록)

모던하고 깔끔한 웹 기반의 할 일 관리(Todo) 애플리케이션입니다.  
사용하기 쉬운 인터페이스와 로컬 스토리지(LocalStorage) 연동으로 일정을 효율적으로 관리할 수 있습니다.

---

## ✨ 주요 기능 (Features)

- **할 일 추가/삭제**: 새로운 할 일을 빠르게 추가하고 필요 없는 항목을 삭제할 수 있습니다.
- **상태 관리**: 할 일의 완료 여부를 체크박스로 직관적으로 설정할 수 있습니다.
- **필터링 기능**: `전체`, `진행중`, `완료` 상태별로 할 일을 분류해서 모아볼 수 있습니다.
- **완료 항목 일괄 삭제**: 완료된 할 일들을 한 번에 정리할 수 있습니다.
- **실시간 통계**: 전체 및 완료된 할 일 수량을 실시간으로 확인합니다.
- **데이터 보존 (LocalStorage)**: 브라우저를 새로고침하거나 닫아도 할 일 목록이 지속 유지됩니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **HTML5**: 시맨틱 웹 구조 설계
- **CSS3**: Modern UI Design (Flexbox, Google Pretendard Font, FontAwesome Icons)
- **JavaScript (ES6+)**: DOM 조작, 필터링 로직, LocalStorage 동기화

---

## 🚀 시작하기 (Getting Started)

별도의 라이브러리 설치 없이 브라우저에서 바로 실행할 수 있습니다.

1. Repository 클론:
   ```bash
   git clone https://github.com/10lilikim/to-do-app.git
   ```
2. 프로젝트 폴더 이동:
   ```bash
   cd to-do-app
   ```
3. `index.html` 파일을 브라우저에서 실행합니다.
